# Architecture decisions

Each significant decision, with the options that were discarded, in
[MADR](https://adr.github.io/madr/) format.

| ADR | Decision |
| --- | --- |
| [0001](0001-stateless-streamable-http.md) | Serve MCP over stateless Streamable HTTP with JSON responses |
| [0002](0002-oauth-with-cognito.md) | Authorize with OAuth 2.1, Amazon Cognito as authorization server |
| [0003](0003-api-gateway-and-lambda.md) | Host on AWS Lambda behind an API Gateway HTTP API |
| [0004](0004-terraform.md) | Define the infrastructure with Terraform, state in S3 |
